METHOD
- Each RFID inherits TAG, SHED, TYPE, BREED, and KID/ADULT from its PDF group's corresponding Counting DB shed(s).
- Example: every RFID under 'Gandhi 3 Sheep' uses Gandhi 3 = Non-Pregnant / Anantapur Sheep / Adult.
- This is a group-level assignment because Counting DB contains shed counts, not individual RFIDs.
- TYPE rule: breed containing 'Sheep' = Sheep; other known breeds = Goat.
- KID/ADULT uses the dashboard rule: K0-K4, F0-F2, F2-Male, F2-Female, ICU-Kid, and Quarantine Kids = Kid; other tags = Adult.
