# EOD Update Template

Use this format for short daily progress updates. Keep each bullet to one sentence and lead with the outcome, not the activity.

```text
EOD Update — [Name] | [Date]

Done today
- [Task/ticket] — brief outcome or status.
- [Task/ticket] — brief outcome or status.

In progress
- [Task] — where it stands, any blockers.

Tomorrow
- [Task] — what you're picking up next.

Blockers / needs
- [Dependency, decision needed, or person to loop in] — or "None".
```
