# Automation coverage — where this stands, 2026-09-24

Written so the next session starts from measurements rather than from the
previous session's summary. Every number here was read off a file or a command
in this repo. Where a number is reported-not-verified, it says so.

## 1. What the branch is

PR #375, branch `automation/lane-fixes`. It began as "make the dashboard checks
actually catch things" and became two separate jobs:

1. making the existing automation honest — checks that could not fail, guards
   that could be switched off, a sweep that defaulted to the live farm;
2. measuring and closing real test coverage for everything shipped since
   2026-08-01.

The second job is the one that matters to the farm. The first was a prerequisite:
you cannot prioritise gaps you cannot see.

## 2. The commit ledger — the denominator nobody had

`tools/dashboard-automation/commit-ledger.jsonl`, derived from `git log`,
regenerated by `make commit-ledger-regenerate`, guarded so a new user-visible
commit cannot land without a row.

- 4,172 commits in range; **2,674 user-visible** (`feat`/`fix`); 1,498 out of
  scope, counted rather than dropped.
- 241 behaviours, grouped by a re-derivable rule (area precedence, then subject).

Baseline at creation: **106 covered · 2,337 claimed · 27 smoke-only · 204 gap.**

`covered` means one thing only: **revert the commit, the test goes red.**
`claimed` means a test file exists beside the change and nobody has checked it.

The ledger it replaced held 125 hand-typed rows citing **6 commits**, while
reporting 87% coverage.

## 3. The 795-row verification

The largest single piece of work. Revert each commit, re-run its package, record
whether anything noticed.

Canonical receipts at the time of writing: **276 proved · 52 disproved ·
252 inconclusive · 253 skipped.** Of rows reaching a verdict, **84% proved,
16% disproved.** Three slices were still running when this was written.

**An earlier figure of 26% disproved was wrong and is retracted.** The prover ran
Postgres-backed tests with no database; they skipped, `go test` still exited 0,
and the sweep read that as "the test passes without the fix". **24 of the 38
rows it first accused were doing their job.** Fixed four ways, including
requiring a printed `--- PASS`/`--- FAIL` rather than trusting an exit code.

Of 20 disproved rows opened by hand: **6 genuinely weak** (repaired, each with a
mutation watched go red), 9 stale verdicts that bite at the tip, 4 mis-scoped,
1 dead suite, 1 real defect, 1 deliberately left open.

`inconclusive` is dominated by build breaks; 61 are commits that added a file and
its test together, so reverting deletes symbols the test needs. That is not
absence of coverage and must not be reported as such.

## 4. The chains — cross-module couplings

57 registered producer→consumer chains. All 57 name an E2E proof; a named proof
is a claim.

Measured: **57 exist · 56 run · 49 bite** — but only **22 went red for BOTH
mutations** (emission deleted, handler no-op'd). For 25, a producer that stops
emitting was invisible to every named proof.

The repeated shape: a producer test counting an outbox row beside a consumer test
that hand-builds the event and calls the handler. Nothing joined them.
`AGENTS.md` already says separate producer and consumer tests are not closure.

**10 chains closed**, each proven red both ways, joined through a helper that
reads the rows the producer's own transaction committed and republishes them on
the production bus. **32 of 57 now protected both ways.**

### The maintainer's own example
"An animal that dies stops being fed" **did not bite.** Every fixture in the feed
projection suite inserted `alive` animals only; neutralising the live-herd
predicate left all 26 tests green. Dead and sold animals would go on being fed,
with a plausible-looking number. Now covered, with the PC Care pen roster
(which had no test at all).

A sweep flagged 20 more packages with the same shape. **7 checked by mutation**
— `animalpurchase` and `penroutines` were genuinely unproven and now bite; four
already did. The flag is a keyword heuristic; the other 11 are unverified.

## 5. Defects found while building the tests

None of these came from reading code. Each fell out of trying to make a check
bite and finding the path underneath already broken.

- **`FindIdentifierMatches` is invalid SQL** (42P01) — the RFID resolve path.
- **`ListRecordedCompletionsByTask` is refused by Postgres** (42P10); the SOP
  verify fan-out could not list what a review fans out over.
- **A placement rule fails open** — `TestCompleteShiftingIntoUnconfiguredShedFailsClosed`
  is red at HEAD and at base.
- **`vaccinationGapsSQL` multi-tag fan-out** — a duplicate spends a LIMIT slot on
  a keyset scan, so genuinely-gapped animals fall off the page. Fixed red-first;
  two more sites carry it.
- **`cmd/partition-maintainer` calls a function migration 000212 dropped**, and is
  still scheduled daily in `workers.json`. **Live, not a test problem.**
- **Two suites that had never run**: `cmd/migrate`'s replay guard (repo-root path,
  `go test` runs in the package dir) and `boardsource` (all eight dying at seed).
- **20 of 67 Postgres test packages red at this tip**, ~15 genuinely.
- **The whole vaccination SOP E2E path was dead** — three stacked causes.

## 6. Android — deferred, documented

`docs/engineering/android-test-coverage-handover.md`.

584 rows, **79 gaps, 0 proven.** 9 of 22 feature modules hold a Kotlin test
against 62 of 73 backend modules. Zero proven because the revert-prover matches
`^backend/.*_test\.go$` only — a tooling gap, not a judgement on the tests.

**Worse than the gap count suggests: `:core:core-data` does not link its
unit-test resources, so ~83 test files there run in no CI path at all.**
`make ci-local` runs `:app:testStgReleaseUnitTest` and nothing else on Android.

## 7. Admin-web — blocked, not skipped

839 rows, **809 claimed, 0 proven, 3 gaps.** Proving a web test needs a rendered
page and there is no browser prover. This cannot move without a database to run
the app against.

## 8. What was built and never run

- **The delta lane** (`delta-lane`): 11 transition checks over two read-only
  snapshots — did the farm's data change legally overnight. 11/11 mutation-proven,
  22/22 (check, reading) pairs say "not checked" rather than "fine" when a reading
  is missing. `comparability()` refuses to compare across a migration, redeploy,
  different farms or the wrong order. **Never pointed at `goatos-stg`.**
  Not wired into `run.mjs`, so nothing reaches Slack.
- **The interactive-surface probe**: 148 surfaces, 21 stated, **0 proven**.
  Refuses deployed hosts, a principal that names nobody, a stale ledger, a route
  that redirected somewhere real, a backend that redeployed mid-run.
- Both OCI timers remain **disabled**. When they return it should be one
  supervised cycle, not a timer.

## 9. Known gaps in the automation itself

- **The FCR-by-pen Slack chart clips its pen labels** (`C..`). Nothing catches it:
  the pen-label checks look for a *wrong string*, and `C..` is a *correct string
  the layout cut off*. More importantly it is a **Slack image, not a page** — the
  route sweep can never see it. §6.3 of the handover records the CSS fix as
  one line, still unpushed.
- `check-guard-integrity --all` takes 17+ minutes; deliberately not on the
  default path.
- The browser-test manifest is derived by probe rather than grep, because grep was
  wrong in both directions. Two routes to a browser are demonstrated (direct
  launch, child process); a third (transitive import) was asserted earlier and
  **has no evidence**.

## 10. The lesson, because it repeated all day

Every number that sounded good got smaller when measured, and **the measurements
themselves were wrong at least six times** — including inside a measurement of
that very defect. What caught them was never review. It was mutation testing,
positive controls, and people reporting their own mistakes unprompted.

Two specific traps worth carrying forward:

- **`command | tail` reports the exit code of `tail`.** This produced a suite run
  on a conflicted tree, a refusal reported as a pass, a push on red, and a guard
  reported red that was green.
- **Ask which direction a missing input pushes the answer.** Failing toward
  silence is a defect; failing toward accusing correct work is worse. A pin audit
  recommended MORE widening with its stylesheet missing. A guard printed "539
  files scanned" with the tree deleted.
