# Mesha Exchange prototype — builder conventions

App: `~/mesha/exchange-proto/app` — the purchased **Minimal v7.7.0 TypeScript** starter (Vite + MUI v9), Mesha brand palette in `src/theme/theme-config.ts` (locked: never add hex colours or change the palette; use theme palette keys like `primary`, `info`, `secondary`, `warning`, `success`, `error`, `text.secondary`, `background.neutral`).

Full template for visual reference (read, copy components/sections from it): `~/mesha/mui/Minimal_TypeScript_v7.7.0/vite-ts/src` — e.g. `sections/user/view/user-list-view.tsx` (list pages: tabs with count Labels, toolbar, TableHeadCustom, TablePaginationCustom, dense switch), `sections/user/user-new-edit-form.tsx` (create/edit form layout), `sections/invoice/invoice-details.tsx` (statement), `sections/account/*` (profile/security), `sections/overview/banking/*` and `sections/overview/app/*` (dashboards, charts). Copy what you need into `app/src/sections/...` (drop mock/_mock imports). Match Minimal exactly: Card, CardHeader, Grid spacing 3, Label variant soft, Scrollbar around tables, `DashboardContent`, `CustomBreadcrumbs`, charts via `src/components/chart` (`useChart`, `Chart`, `ChartLegends`).

Behaviour reference (the reviewed working prototype, plain JS): `~/mesha/exchange-proto/mesha-exchange.html` — functions `CEO.*`, `LP.*`, `DLG.*` show what each page shows and does.

Data + rules: `src/exchange/store.ts` (all maths, permissions, actions returning `{ok,msg}`; call actions, never mutate `S` from pages). React: `const X = useExchange()` (re-renders on change) and `const { actor, lp } = useSession()` from `src/exchange/hooks`. Show results with `report(r)` from `src/exchange/dialogs` (Minimal snackbar). Permission-gated buttons: `GateButton need="do|oversee|configure" pool={id}`. Existing shared bits: `Page`, `WidgetSummary`, `Rows`, `NoAccess` (`src/exchange/components`), `RecordInvestmentButton`, `NewPayoutButton`, `ReverseButton` (`src/exchange/dialogs`). Asset-class colours: `CLASS_COLOR` in hooks. Pattern page: `src/exchange/pages/ceo/dashboard.tsx`.

Rules:
- Only edit the page files you own (plus new files you create under `src/sections/` or `src/exchange/pages/**`). Do NOT edit `store.ts`, `hooks.ts`, `shell.tsx`, `dialogs.tsx`, `components/index.tsx`, theme or layouts; if you need a helper, write it in your page file. If a store bug blocks you, say so in your final report.
- CEO pages: if `X.grant(actor)` is none → `return <NoAccess actor={actor} />`; always scope to `X.poolsFor(actor)` / `X.investorsFor(actor)`; mask PII unless `X.canPII(actor)`.
- Money never wraps: `whiteSpace: 'nowrap'` on amounts; use `X.fm(v,'INR',{c:1})` compact on cards.
- Every page must look right at 1440, 1024 and 390 px (mobile webview): Grid sizes `{ xs: 12, md: … }`, tables inside `Scrollbar`, forms one column on xs. Primary buttons `color="primary"`. Icons: only names already in `src/components/iconify/icon-sets.ts` (offline; no network icons).
- Build: `cd ~/mesha/exchange-proto/app && npx vite build --outDir dist-<you>` then serve it `python3 -m http.server <port> -d dist-<you>` (A=8771, B=8772, C=8773) and check in your OWN browser tab (`mcp__Claude_Browser__tabs_create`); URLs are hash routes, e.g. `http://localhost:8771/index.html#/ceo/pools`. Check the console for errors, take screenshots at 1440×900 and 390×844 and LOOK at them. Reset viewport to desktop when done.
- Never add process notes to the UI. Copy is short, plain English.
