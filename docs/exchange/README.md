# Mesha Exchange

Mesha Exchange is the investor (LP) portal and CEO console for Mesha investment
pools built on Goat OS parks.

It is a separate product, service, database, and repository:

- GitHub: https://github.com/vgoats/mesha-exchange
- Shared UI reference: https://github.com/vgoats/mesha-ui
- Domain: `exchange.mesha.sg`

Keep the system design, UI spec, build notes, and prototype in
`vgoats/mesha-exchange`. Goat OS should keep only integration contracts needed
for the narrow operational read APIs that Mesha Exchange consumes.
