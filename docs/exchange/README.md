# Mesha Exchange

Investor (LP) portal and CEO console for Mesha investment pools built on goatos parks.
Separate product: `exchange.mesha.sg`, own repo/GCP project (see system design).

- [system-design.md](system-design.md) — architecture, data model, unit/NAV maths (forward pricing), security layers, HRMS-driven access, feature flags, edge cases, build order.
- [minimal-ui-spec.md](minimal-ui-spec.md) — measured MUI Minimal UI reference (cards, tables, forms, charts) with the Mesha palette locked.
- [prototype-build-notes.md](prototype-build-notes.md) — conventions used to build the React prototype on the purchased Minimal v7.7 template.
- [../prototypes/mesha-exchange-prototype.html](../prototypes/mesha-exchange-prototype.html) — self-contained working prototype (CEO view, LP view, mobile, system design). Open in a browser; data is saved locally.

The React prototype on the licensed Minimal template is kept outside this repo (template source is licensed and not redistributed here).
