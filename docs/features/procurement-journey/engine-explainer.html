Same problem, two ways

Truck runs 6 hours late. Who handles it?

What is Temporal

A coordinator that writes every step in a diary.

Server crashes? A new one reads the diary and carries on from the same step. Nothing redone, nothing lost.

What is a saga

Saga = forward journey + a planned recovery path for every important step.

One long deal cannot sit in one database transaction. Each step completes on its own; if the journey cannot continue normally, the saga runs the planned recovery. Temporal is the engine that remembers and runs it.

Undo has a limit

Once the truck leaves, you can't undo. You recover forward.

Real life changes the plan

Seller promised 70, only 50 are acceptable. The saga branches, not a blind undo.

Dispatch moves from 18th to 16th. Everything tied to it moves too.

Who owns the clock

GoatOS keeps every deadline and chase. The coordinator decides what's next.

How it fits GoatOS

GoatOS stays as it is. Temporal runs only this journey.
