1 · System design

GCP-native, modular monolith on Cloud Run. Postgres = source of truth; Cloud Tasks holds only near-term timers. No Temporal/Redpanda/n8n; no Kubernetes.

2 · ER diagram (core relationships)

How the engine, the modules, and the committed identity/location/team tables connect. Module tables attach to obligation_instances via obligation_id.
