Real UX pass — not just paint

  • Tap-to-pick date pickers (tap DOB / Entry → calendar) instead of typing a date string — kills format typos and makes DOB ≤ entry enforceable in the UI.
  • Smart defaults prefilled: Entry = today (23 Jul 2026), Species = Goat, Sex = Female. Common case = scan tag, pick DOB, submit.
  • Optional fields collapsed under "＋ Add details" (Tag 2, Breed) and "＋ Dam" — the required path is short; extras are one tap away.
  • Grouped into cards (Identity / Dates / Placement) and bigger touch targets (54px fields, chunky segments) for gloved hands in a shed.
  • Every real control kept — Tag1*, Tag2, Species, Sex, Breed, DOB*, Entry*, farm→shed placement, Dam; Death: search/match/target-card/Reason* + server-fixed died/dead guardrail.
