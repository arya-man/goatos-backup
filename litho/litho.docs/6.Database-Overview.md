### Tables

#### main.bootstrap_cache

Android Room (SQLite) cache table storing serialized bootstrap DTO payloads with an update timestamp, used by the goatos-android app for local caching of bootstrap/session data. Present consistently across schema versions 28 through 63 of the GoatDatabase.

**Source:** `./apps/goatos-android/core/core-data/schemas/sg.mesha.goatos.core.data.GoatDatabase/63.json`

| Column | Type | Nullable | Identity |
|--------|------|----------|----------|
| id | INTEGER | No | Yes |
| dtoJson | TEXT | No | No |
| updatedAt | INTEGER | No | No |

**Primary Key:** id

#### public.goats

Canonical animal (goat) record table used across the platform as the source of truth for herd census and mortality analytics. Referenced by the analytics cube model with tenant_id-based security scoping. Documented plan to migrate consuming analytics to ceo_ai.animal_current_scope.

**Source:** `./analytics/cube/model/cubes/animals.yml`

| Column | Type | Nullable | Identity |
|--------|------|----------|----------|
| tenant_id | unknown | No | No |

#### public.locations

Location dimension table providing park/shed labeling data, joined with the goats table to support census and mortality dimensional analysis in the analytics cube model.

**Source:** `./analytics/cube/model/cubes/animals.yml`

#### ceo_ai.animal_current_scope

Planned/target governed reporting table (documented migration path) intended to replace direct joins on public.goats for census/mortality metrics, combined with mortality data under the ceo_ai reporting schema used by the CEO-AI assistant's SQL guard tier.

**Source:** `./analytics/cube/model/cubes/animals.yml`

#### public.funnel_daily

Postgres analytics rollup table storing daily GA4 funnel aggregation metrics, upserted by the analytics-rollup batch job sourced from BigQuery GA4 export partitions.

**Source:** `./backend/cmd/analytics-rollup/main.go`

#### public.journey_daily

Postgres analytics rollup table storing daily user journey aggregation metrics, upserted by the analytics-rollup batch job sourced from BigQuery GA4 export partitions.

**Source:** `./backend/cmd/analytics-rollup/main.go`

#### public.engagement_daily

Postgres analytics rollup table storing daily engagement aggregation metrics, upserted by the analytics-rollup batch job sourced from BigQuery GA4 export partitions.

**Source:** `./backend/cmd/analytics-rollup/main.go`

#### public.crash_daily

Postgres analytics rollup table storing daily crash aggregation metrics, upserted by the analytics-rollup batch job optionally sourced from Crashlytics BigQuery exports.

**Source:** `./backend/cmd/analytics-rollup/main.go`

### Views

#### analytics.animals

OLAP cube (Cube.js model, functionally analogous to a reporting view) providing census and mortality analytics for livestock. Joins the canonical goats table with locations for park/shed labeling. Defines governed measure formulas intended to remain stable across underlying source table migrations.

**Source:** `./analytics/cube/model/cubes/animals.yml`

**References Tables:** public.goats, public.locations

### Data Flows

#### GA4 Analytics Rollup Pipeline

- **Source:** BigQuery GA4 export partitions (and optional Crashlytics exports)
- **Destination:** Postgres analytics tables (funnel_daily, journey_daily, engagement_daily, crash_daily)
- **Operations:** SELECT, AGGREGATE, UPSERT
- **Procedures:** ./backend/cmd/analytics-rollup/main.go

#### Outbox Event Relay and Dead-Letter Handling

- **Source:** Postgres outbox table
- **Destination:** External event bus / Pub/Sub (with DLQ fallback)
- **Operations:** SELECT, PUBLISH, UPDATE (mark processed), MOVE_TO_DLQ
- **Procedures:** ./backend/cmd/outbox-relay, ./backend/cmd/outbox-dlq/main.go

#### Domain Event Consumption and Repair

- **Source:** Domain event bus (Pub/Sub)
- **Destination:** Postgres domain tables (obligation, inventory, protocol, vaccination schemas)
- **Operations:** CONSUME, INSERT, UPDATE
- **Procedures:** ./backend/cmd/domain-event-consumer, ./backend/internal/domainconsumer

#### Database Schema Migration

- **Source:** SQL migration files (backend/migrations/postgres)
- **Destination:** PostgreSQL database schema
- **Operations:** DDL_APPLY, VERSION_TRACK, HASH_VALIDATE
- **Procedures:** ./backend/cmd/migrate/main.go

#### SOP Review Fanout Retry

- **Source:** Inventory / Obligation Postgres repositories
- **Destination:** Vaccination completion fanout events
- **Operations:** SELECT, RETRY, PUBLISH
- **Procedures:** ./backend/cmd/sop-review-fanout-retry/main.go

#### Android Bootstrap Cache Persistence

- **Source:** Bootstrap API response (DTO)
- **Destination:** Local SQLite bootstrap_cache table (Room)
- **Operations:** SERIALIZE, INSERT, UPDATE
- **Procedures:** ./apps/goatos-android/app/src/main/kotlin/sg/mesha/goatos/boot/BootstrapViewModel.kt, ./apps/goatos-android/app/src/main/kotlin/sg/mesha/goatos/di/AppModule.kt
